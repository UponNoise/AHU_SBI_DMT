# 转学学分兑换与成绩要求

来源：安徽大学石溪学院《2022级石溪转学课程学分兑换成绩要求一览表》。

## 覆盖专业

- 数字媒体技术（DMT / ISE）
- 应用统计学（AMS）
- 应用物理学（PHY，本仓库暂以索引预留，资料可后补）

## 使用方式

1. 查某专业某学期课表：见 [`curricula/`](../../curricula/)。
2. 查某门课资料与兑换信息：见 [`课程资料/<课号-课程名>/README.md`](../../课程资料/)。
3. 可将官方 Excel 放在本目录（大文件可用 Git LFS 或外链）。

## 关键门槛摘要（2022 Cohort）

| 专业 | 关键组合课 | 单科线 | 组合均绩 |
| --- | --- | --- | --- |
| DMT | AMS151, CSE114, ISE218 | 相关课 75+ | 4 分制 ≥ 3.0 |
| AMS | AMS151, AMS161, MAT203, AMS210 | 线代/微积分 III 等 75+，其余见课表 | 4 分制 ≥ 2.8 |

具体以学院最新通知与官方一览表为准。
