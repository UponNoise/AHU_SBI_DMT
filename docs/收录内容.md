# 收录内容

## 组织方式

- **物理存放**：`课程资料/<课号-课程名>/{通用资料,Quiz,作业,试卷,Practice,复习资料}`
- **逻辑索引**：`curricula/DMT`、`curricula/AMS` 按学期链到课程目录
- **制度文档**：`docs/`

## 资料类型

| 目录 | 内容 | 年级后缀 |
| --- | --- | --- |
| 通用资料 | 课件、教材、大纲、跨届通用参考 | 不加 |
| Quiz | Quiz 题与解析 | 新增需 `__20XX级` |
| 作业 | 作业、实验、项目 | 新增需 `__20XX级` |
| 试卷 | 期中、期末、模拟卷 | 新增需 `__20XX级` |
| Practice | 练习、题库、例题 | 新增需 `__20XX级` |
| 复习资料 | 笔记、总结、提纲 | 新增需 `__20XX级` |

## 不收录

- 含真实姓名、学号、邮箱、手机号、账号等个人标识的文件
- 单个超过 100MB 且未使用 Git LFS 的文件
- 破解工具、激活码等侵权或违法内容
