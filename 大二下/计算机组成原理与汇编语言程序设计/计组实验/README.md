## Lab_10 单周期 CPU 设计

此实验需要配置同文件夹下的 cs3410.jar 文件，将两个文件放在同一目录下，再使用 Logisim 打开。实验内容在打开后的单周期 MIPS （硬布线）内，其中单周期硬布线控制器也是实验的一部分，这里都已经直接给出。测试时将老师给的 .asm 文件汇编成 .hex 后右键图中的 ROM，选择 Load Image 选项上传。之后每次 Ctrl+R 重置后 Ctrl+K 运行。当 PC 不再变化即运行结束，再次 Ctrl+K 停止即可。此时右键 RAM 选择 Edit contents 查看 080 行的数，若为降序排列则功能正常。
