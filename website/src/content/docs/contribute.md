title: 参与贡献
description: 帮助补充课程资料或修正索引信息。
---

欢迎补充课件、作业、试卷、练习和复习资料，也欢迎修正课程名称、学期归属或失效链接。

## 提交前检查

- 删除姓名、学号、邮箱等个人信息。
- 使用能说明内容的文件名，避免“新建文档”“未命名”等名称。
- 确认资料允许分享，不上传答案泄露、商业盗版或受限制内容。
- 尽量放入对应课程和资料分类，避免重复文件。

## 前往仓库

- [阅读完整贡献指南](https://github.com/UponNoise/AHU_SBI_DMT/blob/main/CONTRIBUTING.md)
- [在 GitHub 打开项目](https://github.com/UponNoise/AHU_SBI_DMT)

如果课程目录还不存在，可以先提交 Issue，说明课程代码、课程名称和建议归属。
