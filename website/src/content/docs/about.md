这个网站是 AHU SBI 课程资料仓库的轻量索引。它不会复制数 GB 的课件，而是将课程、培养方案与 GitHub 中的资料目录连接起来。

## 怎么使用

1. 在首页或“全部课程”中输入课程名或课程代码。
2. 继续按专业、学期、资料类型和库存状态缩小范围。
3. 进入课程详情，选择资料分类后前往 GitHub 查看或下载文件。

筛选条件会保存在地址栏中，可以直接复制链接分享给同学。

## 数据范围

- 学期分配沿用本仓库维护的课表数据。
- 学分、石溪认证和前置课程要求参考学院公布的 2022 级课程设置。
- 资料数量来自仓库实际文件库存，并在索引生成时更新。

:::caution[请以学院通知为准]
本项目由学生维护，并非学院官方网站。培养方案、转专业要求和课程安排可能随年级调整，请始终以学院最新通知为准。
:::

## 隐私与版权

资料仅供学习交流。提交前请移除姓名、学号、联系方式等个人信息，不要上传受限制传播或来源不明的内容。
