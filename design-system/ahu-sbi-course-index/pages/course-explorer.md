# Course Explorer Override

This page is a compact search application, so these rules override the landing-page rhythm in `MASTER.md`.

- Keep search first and visually dominant; filters follow in one aligned grid.
- Use a sticky filter panel only when it does not cover content; disable stickiness on narrow screens.
- Every input, select, clear control, and reset control must have a minimum 44px target.
- Active filters are removable chips with text labels, not icon-only controls.
- Course cards use equal-height rows on desktop and one column on mobile.
- Course code, availability, file count, course name, placement, and category summary follow that scan order.
- Use 12px as the minimum supporting-text size and tabular numerals for counts.
- Preserve visible focus rings and full-card keyboard activation.
- Test layouts at 375px, 768px, 1024px, and 1440px with no horizontal overflow.
